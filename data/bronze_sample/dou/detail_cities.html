Trainee / Junior PHP Developer

Київ, Львів, Івано-Франківськ, Тернопіль

ELEKS Software Engineering and Development Office is looking for a Trainee / Junior PHP Developer in our offices in Ukraine.


Our project is a German event management and marketing platform that helps customers create events with different ticket categories, sell tickets, analyze event performance, and collect feedback from organizers.
Our client works with large companies that organize conferences, trade fairs, and other corporate events.

REQUIREMENTS

  • Understanding of programming fundamentals and how software is built

  • Basic knowledge of PHP 8.4 and object-oriented programming; hands-on PHP experience is a plus but not mandatory

  • Openness to learning PHP with Laminas or writing backend code in Node.js

  • Basic understanding of relational databases and SQL; familiarity with MySQL 8.4 or PostgreSQL 14

  • Basic understanding of REST APIs

  • Familiarity with Git and Composer

  • Some hands-on experience with AI tools for software development

  • Ability to use AI thoughtfully: define tasks and acceptance criteria, review and test AI-generated output, and refine it where needed rather than copying it without verification

  • Interest in a full-stack role and willingness to work across both backend and frontend development
  • Upper-Intermediate level of English

WOULD BE A PLUS

  • Familiarity with TypeScript and Angular 21
  • Experience with PHP or another backend language
  • Basic knowledge of Docker
  • Familiarity with PHPUnit and test writing
  • Interest in AWS services such as S3 or SQS
  • Basic knowledge of NoSQL databases, such as DynamoDB
  • Familiarity with Swagger/OpenAPI, Propel ORM, or microservices
  • Experience working with third-party APIs, such as PayPal or Google Analytics

RESPONSIBILITIES

  • Conduct a simple range of programming tasks including analysis, coding, and debugging of complex program logic
  • Conduct test procedures by using testing, and debugging programs
  • Develop algorithms according to technical specifications or other requirements documentation
  • Use standard algorithms in the applicable cases
  • Write program code according to the defined application architecture
  • Structure and format source code, comment and mark up the code, as well as name variables, functions, classes, data structures, and files according to the company conventions and industry best practices
  • Track changes, compare source code in the defined version control system
  • Agree task deadlines with Senior Developer or Technical Leader

WHAT YOU WILL GET WITH ELEKS

  • Close cooperation with a customer
  • Challenging tasks
  • Competence development
  • Team of professionals
  • Dynamic environment with a low level of bureaucracy

ABOUT ELEKS

ELEKS is a custom software development company. We deliver value to our clients, thanks to our expertise and experience gained from working as a software innovation partner since 1991.

Our 2000+ professionals located in the Delivery Centers across Eastern Europe and sales offices in Europe and North America, provide our clients with a full range of software engineering services. These include product development, QA, R&D, design, technology consulting and dedicated teams.
